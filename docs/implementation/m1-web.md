# M1 Web 实施与验收

日期：2026-11-12；事前基线先于Web实现保存。范围及内部说明见[Web实施规格](../specifications/m1-web.md)，共同接口以[HTTP规格](../specifications/http-api.md)为准。当前结果：实施中；不能据此宣布首版贯通。

## 1. 顺序与运行环境

1. 保存本规格及W01—W10；核验并固定Vue／TypeScript／Vite／Vitest及测试依赖版本、许可证和Node兼容性。
2. 为运输、提交恢复、并发保存、冲突及权限代次先写失败测试，再实现`web/src/api.ts`、`config.ts`、`submissions.ts`和`model.ts`。
3. 实现Vue登录／节点、配置编辑／部署、操作结果及账号／授权／认领界面，增加组件交互测试。
4. 执行全部Web测试、类型检查及生产构建；核对文档与最终代码，交独立审阅；再由首版集成连接真实Manager／Agent验证。

已读取环境：Windows PowerShell，Node 24.15.0，npm 11.12.1。浏览器运行须同源HTTPS及现代UTF-8／fetch／crypto.randomUUID支持。不以开发服务器代理替代正式Origin／Cookie验证。测试替代fetch仅用于可控响应顺序，不进入运行产物。

## 3. 完成条件与限制

源码切片交接要求W01—W10适用前端测试通过及独立审阅。正式HTTPS Cookie行为、真实后台权限、账号禁用、两节点隔离、原生Compose和重开恢复均须与正式服务联调；前端假响应测试不能使首版V01—V08通过。没有真实服务之前保持这些端到端项未验证。禁止在页面放运行时假节点／假成功数据。
