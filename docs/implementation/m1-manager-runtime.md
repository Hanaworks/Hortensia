# M1 Manager运行实施与验收

2026-11-12编码前保存；依赖服务v4内核及HTTP适配器，当前未实现。[运行规格](../specifications/m1-manager-runtime.md)给出文件、锁、生命周期与失败边界，本篇保留稳定RT编号和实际实验结果。全部本地结果与Linux交付分别记录。

## 实施顺序

1. 配置、identity和安全文件读写失败测试，再实现无数据库的运行基础。
2. 操作系统排他锁与真实第二进程竞争测试，再接init的独占文件发布和CreateService。
3. 接HTTP服务、TLS和取消，验证真实进程初始化、启动、登录及关闭；不把httptest单独当进程通过。
4. 复核文档、全量关联回归及Linux构建，Linux权限／目录同步实测等待用户环境安排。
