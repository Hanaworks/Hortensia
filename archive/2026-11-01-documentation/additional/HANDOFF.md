## 关键背景

- 节点独立运行，以 Node → Docker 资源 / Stack（Compose）组织管理；目前不以集群调度为目标。
- Web UI 应完成创建、查看、编辑 Compose 与环境配置、部署的日常流程，不要求用户先 SSH 到服务器创建文件。
- 以原生 Compose 行为为准，管理器不擅自增加网络、卷等部署内容。
- Node Cross 是核心方向：将某个节点的 Stack 配置方便地用于另一节点部署。
- 数据迁移是可选扩展，不应成为实现配置跨节点操作的前提。
- 参考 Portainer 的主体，逐项决定沿用、调整、新增和暂缓；不是默认全量复刻。
- UI 在实现相关功能时逐步细化，不用先完成整套视觉和页面设计。
