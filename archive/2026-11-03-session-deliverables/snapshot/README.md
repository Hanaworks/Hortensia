# Docker Manager

自托管的多节点 Docker 管理器。多节点管理和迁移体验参考 PVE，节点内的 Docker 资源操作与 Compose 管理参考 Portainer，支持多人按节点或操作授权。Node Cross 用于跨节点迁移；Copy、Apply 类操作用于独立的配置复制与部署。覆盖内外网混合节点，以约 20 个节点作为参考规模，提供分组、标签和 docker run 转 Compose 工具。

当前阶段：需求与设计文档编写。应用尚未实现，技术栈尚未确定。

当前以 Linux、FreeBSD 这类 Unix-like 环境为使用背景，优先实现可用 Docker CLI／Compose 下的一致行为，暂不扩展跨平台适配。Compose 配置遵循 Docker 原生规则，不提供 Build、Dockerfile 和构建上下文支持。

多人使用采用已确认的可信运维协作模式，按节点和操作授权；任意部署权限属于对相应节点的高信任授权，本轮不提供同节点不可信租户强隔离。
